# 話せるようになる語学（韓国語・フランス語・英語）

ブラウザだけで動く語学学習アプリです。`index.html` を開くと使えます。

- **韓国語**：今日始める人向け。ハングル10ステップ（読む・聞く・組み立てて書く・手で書く）→ 文のステップ
- **フランス語**：30日コース（説明は英語／日本語を切り替え可）
- **英語**：レベル1〜10（中学1年〜TOEIC 990超）。レベル診断、長文＋和訳、TOEIC形式リスニング（Part 2・3・4）

共通の仕組み：間隔反復（FSRS）、読む・聞く→書く→言うの順に増える復習カード、耳トレ、シャドーイング、ランクとバッジ。

## 注意

- 学習記録は開いた端末のブラウザに保存されます（「バックアップ」で書き出し・復元できます）。
- 音声は端末の読み上げ機能を使います。韓国語・フランス語・英語の音声が端末に入っている必要があります。
- AIを使う機能（会話ミッション、やさしい物語、長文やリスニングの追加作成、音声入力）は、Claude のアーティファクトとして開いたときだけ動きます。GitHub 上のページではこれらは自動で隠れ、AIなしの練習になります。
- 英語の長文は、どの単語もタップすると内蔵の辞書で意味が出ます（AI不要）。
- 長文・問題はすべてこのアプリ用の書き下ろしです。教科書や TOEIC 公式問題の転載ではありません。

## ファイル

- `index.html`：アプリ本体（これ1つで動きます）
- `src/`：`index.html` の中身を部品ごとに分けたもの（データとコード）。読むため・直すための参考用です。
