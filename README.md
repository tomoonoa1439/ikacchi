# イカッチ

イカの たまごを ふかして そだてる、たまごっち × どうぶつの森 風の ブラウザゲームです。
ビルド不要・サーバー不要・アカウント不要。絵文字は使わず、アイコンはすべて `js/icons.js` のオリジナルSVGです（どの機種でも同じ見た目）。HTML/CSS/JavaScript（ESモジュール）だけで動きます。

## あそびかた

| じき | できること |
|---|---|
| たまご | あたためる（緑の帯の温度をキープ）／みずかえ／はなしかける |
| イカ | ごはん／おふとん／トイレ／そうじ／あそぶ（どっちむく？）／おくすり |
| イカ（v0.3〜） | しかる（わがままの とき）／しらべる（ねんれい・たいじゅう・しつけ・おせわミス）／でんき |
| いつでも | ショップ／すなほり／ずかん（アルバム）／ともだち／にっき／ひっこし |

- **イカの しゅるい（v0.4）**：たまごから うまれる イカは ランダム。ももイカ／ネオンイカ／さばくイカ／ゆきイカ／ほしぞらイカ と、めったに でない レアの にじイカ（約3%）。ずかんの「すがた」で あつめた しゅるいが みられる
- **成長**：あかちゃん → こども → おとな。おとなの タイプは こども期の おせわで 4つに 分かれ、しゅるいの まえに つく
  （ひかる＝ミスなく丁寧に＋しつけ／ビッグ＝たくさん食べる／ひらひら＝たくさん遊ぶ／のびのび＝ふつう）。例：「ひかる ネオンイカ」
  （ホタルイカ＝しっぱい少なく丁寧に／ダイオウイカ＝たくさん食べる／アオリイカ＝たくさん遊ぶ／スルメイカ＝ふつう）
- **時計と天気**：昼夜は実際の時刻と連動。天気は日付で決まり、全プレイヤー共通（雨・にじの日はレアが出やすい）
- **かいがら**：おせわ・すなほり・毎日ボーナスで たまり、ショップで ごはん・きせかえ・家具を買えます
- **ずかん**：すなほりで見つけたものを集める。2こ目以降は売れます
- **なかよし度**：おせわするほど Lv が上がります
- **たまごっち要素（v0.3）**
  - よるは じぶんで ねる → でんきを けしてあげる（つけっぱなしは おせわミス）
  - わがまま → しかると しつけが あがる（ふつうの ときに しかると かなしむ）。しつけが ひくいと ごはんを いやがることも
  - よびだしを 15ふん ほうっておくと「おせわミス」。ミスが すくないほど いい すがたに なる
  - たいじゅう：おやつで ふえ、あそぶと へる。ふとりすぎは びょうきの もと
  - 1にち＝1さい。3にち くらいで ひろい うみへ たびだち → アルバムに のこって つぎの せだいの たまごが くる
  - ミニゲーム：どっちむく？／スミでっぽう

## ともだち（アカウント不要・リンクを タップするだけ）

1. ともだち →「リンク」で 名前を入れて **ともだちリンクを おくる**（スマホなら LINE などの 共有画面が ひらく）
2. 受けとった人が リンクを タップすると、相手のイカが 部屋に あそびに来ます（1日1回いっしょに遊べる）
3. 「プレゼント」で もちものを リンクにして送れます。同じリンクは 1回しか受けとれません
4. ひっこし：きしゅへんこうの ときは ひっこしリンクを 自分に送って 新しいスマホで ひらく
5. **かんけい（v0.5）**：あそびに きた ともだちを タップ（または 画面ひだりうえの なまえ）すると、あそぶ・おしゃべり・プレゼント ができる
   - しりあい → ともだち → なかよし → しんゆう → こいびと と すすむ（こいびとは しんゆうで、ふたりとも おとなに なってから）
   - きげんが わるい・おなかが すいてる・わがまま中 だと けんかしやすい。「ごめんね」か プレゼントで なかなおり。じかんを おいても なおる
   - なかよしいじょうの こは、ほかの こと あそんだ日に くると やきもちを やく
   - しんゆうで なかよし度が たかいと、あいてから こくはく されることも
   - かんけいは じぶんの セーブデータの中だけで すすむ（あいての 画面には まだ はんえいされない）

## ファイル構成

```
index.html
css/style.css
js/config.js   … バランス・アイテム・イカの しゅるい・ずかん・進化・天気の データ（ここを触るだけで追加できる）
js/state.js    … セーブデータの形・読み書き・マイグレーション・イベントバス
js/sim.js      … 時間経過（おなか・トイレ・成長・進化・るす中の計算）
js/actions.js  … プレイヤー操作。すべて dispatch(type, payload) を通る
js/social.js   … ともだちとの かんけい（けんか・なかなおり・やきもち・こくはく）
js/net.js      … ネットワーク層（いまは LocalCodeAdapter）
js/art.js      … イカ・たまご・ぼうしの SVG
js/icons.js    … ボタンやアイテムの オリジナルアイコン（SVG）
js/ui.js       … 描画・モーダル・ミニゲーム
js/main.js     … 起動とゲームループ
```

## 公開のしかた（だれでも遊べるURLにする）

ESモジュールを使っているので、`index.html` を ダブルクリックでは開けません。どれかで公開してください。

- **GitHub Pages**：リポジトリにこのフォルダの中身を置く → Settings → Pages → Branch を main に
- **Netlify / Cloudflare Pages**：フォルダを ドラッグ＆ドロップ
- **手元で試す**：このフォルダで `python3 -m http.server` → http://localhost:8000

## オンラインマルチへの ロードマップ

いまの設計は、次の段階に そのまま進めるように 作ってあります。

1. **ステップ1（実装ずみ）**：コード交換による 非同期マルチ。サーバー不要
2. **ステップ2：オンラインの ともだち** — Supabase か Firebase の **匿名認証**（ログイン画面なし）を使って
   `net.js` に `OnlineAdapter` を作る。`shareProfile / lookupFriend / sendGift / receiveGift` の4つを実装して、
   `export const net = new OnlineAdapter(...)` に差しかえれば UI は そのまま動きます。
   コードの代わりに 8もじの プレイヤーID だけで ともだち登録できるようになります
3. **ステップ3：リアルタイムで おとなり訪問** — 同じ部屋に 入って いっしょに 動く。
   `actions.js` の action（`{type, payload}`）を そのまま WebSocket / Realtime チャンネルに流せば 同期できます
4. **ステップ4：不正対策** — すなほりの抽選や ショップ購入を サーバー側で 行う（今は `actions.js` の中）

> 注意：Claude のアーティファクト内では 外部サーバーへの通信が できないため、オンライン版は
> GitHub Pages などに 置いたものを 使ってください。
